# Designing Agentic Systems with LangChain

This repository contains my personal study notes, hands-on implementations, and code exercises completed as part of the **Designing Agentic Systems with LangChain** course on DataCamp.

## 📌 Focus Areas
- Building ReAct reasoning agents and custom Python tools.
- Multi-step conversational workflows and state management using **LangGraph**.
- Local LLM integrations using **Ollama** (`qwen2.5:latest`) with structured outputs.
